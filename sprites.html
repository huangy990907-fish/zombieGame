烘焙组合精灵（人 + 枪）

不再是实时叠两层：武器已经按 overlay dx=8 / dy=2 压进人物帧，烘焙成一张 32×32 贴图，每种 4 帧（idle / walk1 / walk2 / fire）。 描边现在跟着合成后的外轮廓走，不会出现「人一圈、枪一圈」。每组都标注 anchor（单位中心）、muzzle（fire 帧枪口）、footprintRadius 与像素包围盒。

接入自检（12px 贴地）

每个组合精灵按游戏内 12px 渲染后再放大 10×（禁用平滑），方便肉眼核对中心对位。 青色十字 = anchor（纹理中心，渲染时钉在碰撞体中心）；粉色圈 = muzzle（fire 帧枪口）；灰色虚线圈 = footprintRadius 建议碰撞半径。 最后一张是人类无武器对照。

单体精灵

1× 原生 / 游戏内实际尺寸 / 8× 放大（可开像素网格）。武器是单独精灵，合成效果见上一节。 zombie-death 的倒地序列会按 death-1 → death-2 → death-3 循环播放（游戏内每帧 0.2s，播完停在末帧并淡出）。

俯视 32px 的取舍：只画从上往下能看到的部分——头顶、双肩、向前伸的手臂、靴尖。放弃了正面五官、躯干细节和武器背带等在大尺寸下才成立的东西； 眼睛只保留 2×2 的亮点，因为这是 11px 下唯一还能看出「这是张脸」的像素量。

为什么手臂画在头两侧：32px 下如果让手臂从头前方交叉，缩到 11px 会糊成一个绿团；留 1px 空隙、把双肩画宽，才能在小尺寸下保住「人形」轮廓。 因此枪也不做「双手端平」的姿势，而是按 overlay 偏移放到头部右侧，保证头部和枪管都能看清。

武器剪影（轮廓区分，识别色只是辅助）：机枪＝4px 宽短枪管 + 枪口制退器 + 机匣前亮色提把 + 外张两脚架 + 偏左圆弹鼓（又窄又带「圆屁股」）； 喷火器＝2px 细长枪管 + 机身两侧各一个圆燃料罐（最细、尾部双圆）；霰弹枪＝并排双管中间留 2px 缝 + 横跨双管的宽泵动护木（顶部两条细棱、中段宽箍）； 火箭筒＝15→11→9 三层扩口锥 + 9px 粗管身 + 宽方肩托（上下都外张的喇叭形）。四把枪的「宽度节奏」不同，8px 下不靠颜色也能对上号。

烘焙与接入约定：组合精灵在 src/art/composites.ts 里烘焙成普通 SpriteDef（独立调色板 + 字符矩阵），渲染层只按 id 取图，不需要再叠两层、也不用再算 overlay。 所有精灵统一画成「朝上」（facing: "up"），枪口指向 -y；渲染时把纹理的 anchor 点（32×32 内坐标，人形是 (16,17)）钉在单位逻辑坐标上，再按朝向旋转。 muzzle 记录 fire 帧枪管口位置（合成后 x=24，霰弹枪 x=22，y=5），子弹/火花直接从该点喷出。

关于旋转：当前只烘焙「朝上」一个方向，运行时用线性旋转。像素图转任意角会出现边缘锯齿与轻微糊化；8 方向预烘焙（45° 一档）能明显更稳， 但贴图数量 ×8，需要等接入渲染层时再决定是否值得。

紫色对齐：僵尸与倒戈人类的衣物主色统一为 #8b5cf6（与 HUD 普通僵尸圆点一致），高光 #c77dff（与 HUD 狂奔僵尸圆点一致）， 暗部压到 #4c2a86。皮肤仍为绿色，紫布只占胸口与下摆的破布、肩顶一条亮紫与外缘垂布，避免整只僵尸变成紫色。

倒地三帧：death-1 中弹倾倒（头偏移、双臂下垂、骨盆还撑在地上）；death-2 触地摊开（四肢外张、身位压扁、血泊出现）； death-3 静置（右手外缘收 1px、躯干亮边压暗、血泊外缘再渗一圈）。三帧共用 anchor (16,21)， 渲染层按 0.2s/帧推进，0.6s 播完停在 death-3，最后 0.3s 淡出。
